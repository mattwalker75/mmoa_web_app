Images for the website live here.

- Drop image files into this folder (the admin console's Web App Website page writes here).
- Reference them in the HTML/*.html section files as:  /content/images/<filename>
  e.g.  <img src="/content/images/food-drive.jpg" alt="...">
- They are served by the web app at the /content/images/ URL path.
- Optional: logo.png here is shown on the maintenance screen.
